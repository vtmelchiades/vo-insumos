# vo-insumos

Insumos para refazer do zero o site e o app da assessoria esportiva Vinicius Orefice (Bauru, SP), num teste de modelos de IA.

- `AGENTS.md`: a tarefa e as regras para o agente.
- `BRIEFING.md`: o cliente, a marca, a voz e o que o app precisa fazer.
- `logos/`, `fotos/`, `loja/`: os insumos reais. `referencias-v2-atual/`: telas do app de hoje.
- `site/`: onde o resultado entra.

Os logos e as fotos são da Vinicius Orefice e estão aqui só para este teste. Não use em outro lugar.
